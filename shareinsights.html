01 / About

About ShareInsights

ShareInsights makes it easy for anyone to explore, transform and visualize big, complex data on AWS or Hadoop data lakes in minutes.

The most comprehensive platform for accelerating time-to-insight.

Role

  • Played a hybrid role as UI/UX designer
  • Gathered the requirements and understood the user/client needs
  • Reduced the steps, simplified the journey and made the tool delightful and easy
  • Provided a better experience and UI solution based upon requirements
  • Coordinated with the Account Manager, BA, and back-end / front-end dev teams
  • Provided continuous input during design implementation
  • Did the design QA with the help of the quality team

04 / Users

Personas

Persona 1

Khushal Daruka

BI Developer · 35 · Pune, India

  • General knowledge 83%
  • Program skills 86%

Needs / goals

  • A platform where I can play with big data
  • It should be a cloud web-based platform
  • The UI of the tool should be easier and more user friendly
  • Less time and effort to create a report

Challenges / frustrations

  • Need to ask a developer to create a dashboard every time
  • Install data analysis software on the machine, like Power BI and Tableau
  • Need experience with a BI tool
  • A database administrator background is needed to do the task
  • Python knowledge, scripting languages, and experience with data visualization libraries are obligatory

Workflow improvements

  • Reduce the steps to create interactive dashboards
  • Reduce the time while working with huge datasets
  • Easy query search and merge to segments with common data
