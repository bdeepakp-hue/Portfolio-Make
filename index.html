02 / Process

How I work

The same four moves on every project, scaled to the size of the problem.

  1. Discover

    Find the real problem

    Stakeholder interviews, analytics review, field visits. I leave with a problem statement, not a feature list.

    Interviews
  2. Define

    Frame what's worth solving

    Journey maps and affinity synthesis turn raw notes into a short list of opportunities, ranked by evidence.

    Synthesis
  3. Design

    Prototype in public

    Low-fidelity first, shared early and often with engineering so feasibility shapes the design, not the other way round.

    Prototyping
  4. Validate

    Test, then ship

    Moderated usability testing against clear success criteria, then a measured rollout with a plan to check the metric that mattered.

    Usability testing
